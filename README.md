# Подряд — кликабельный прототип

Прототип маркетплейса стройки и ремонта для Беларуси (пилот — Минск). Один файл `index.html`, без сервера и внешних картинок.

Все компании, люди, отзывы и цены вымышлены; совпадения случайны.

## Стили
Внизу каждой страницы переключатель: Сочный · Инженерный · В духе Yelp · Продуктовый. Структура и карта сайта одинаковые, меняется только оформление. Стиль можно задать в ссылке: `#/search?t=eng` (`juicy`, `eng`, `yelp`, `prod`).

## Экраны (карта сайта — `#/sitemap`)
- `#/` — главная
- `#/search?cat=bath` — поиск с картой Минска
- `#/pro/maystar` — профиль; `#/pro/kroulya` — профиль с пустыми фото и без аватара
- `#/request` — заявка на смету (5 шагов)
- `#/compare` — сравнение смет
- `#/project` — ремонт по этапам, приёмка, отзыв
- `#/join` — регистрация подрядчика, проверка УНП
- `#/cabinet` — кабинет подрядчика, конструктор сметы
- `#/admin` — модерация (демо)

`variants.html` — ранняя страница сравнения стилей, оставлена для истории.

## Сборка
`python3 -I build.py` — собирает `index.html` из `src/index.template.html`, аватары вставляются как data URI. Фото лежат в `photos/`.
